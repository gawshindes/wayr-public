# Example Digest

A weekday tech digest: the day's launches, deals and rulings as short links, grouped by beat. The starting point for your own newsletter.

Made with `wayr onboard`; the structure and voice are generic and meant to be edited.

| Field | Value |
|---|---|
| Name | Example Digest |
| Readers | People who work in or around software and want the day's developments in five minutes, without reading twenty sites. |
| Cadence | weekdays |
| Sources | 6 in `sources.txt` — run `./demo.sh example check` |
| Drafts land in | WordPress drafts, category `Newsletter - Example` |

Files: `sources.txt`, `criteria.md`, `sections.yaml`, `voice.md`, `env.overrides`.
